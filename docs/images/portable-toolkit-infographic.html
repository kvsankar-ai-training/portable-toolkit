portable-toolkit

Developer tools for coding agents on locked-down Windows

When to use it

Your agent uses the machine's tools

e.g. the GitHub Copilot desktop app bundles no Node.js or Python

No administrator rights

corporate laptops where installing software needs a request

Behind a corporate proxy

a proxy that needs Windows (NTLM or Kerberos) sign-in

Before you need it

the document libraries are the largest download; install ahead of time

Setup: one window, one folder

unblock it, then extract

2

in GUI.cmd, or run SETUP.cmd

3

Verify downloads

publisher's hash; stops on a mismatch
